# Ember & Spice — Restaurant Website

A complete, production website for a fine-dining restaurant, with a menu, online table reservations, and an admin dashboard. Built and deployed solo as a demonstration of a full restaurant web product.

**Live demo:** https://restaurant.vardevo.com

## What it does

- **Marketing site** — landing page for a fine-dining restaurant
- **Menu** — full menu presentation
- **Table reservations** — guests book a table; reservations are saved to a database instantly
- **Admin dashboard** — staff view and manage all reservations
- **24/7 bookings** — every reservation is captured, so no table request is lost

## Tech stack

- Front end: HTML5, CSS3 (custom, responsive)
- Backend / database: Supabase (PostgreSQL)
- Hosting: Vercel

## Pages

| Page | Purpose |
|------|---------|
| `index.html` | Landing page |
| `menu.html` | Full menu |
| `book.html` | Table reservation (writes to Supabase) |
| `admin.html` | Staff dashboard to view/manage reservations |
